## Full description

StorageGuard helps you find exact duplicate photos, videos, and documents on Android. See which files match, review where each copy is stored, and choose what to keep.

Scan photos and videos you grant access to, or choose individual files and folders through Android. StorageGuard compares file contents and shows which locations and media your scan could access.

Review each match before cleanup. Choose the copy you want to protect and select any extras yourself. StorageGuard rechecks the selected files and the protected copy before requesting removal. Android asks for approval before moving selected photos or videos to Trash. Permanent deletion of supported local documents is off by default.

File comparison and scan history stay on your device. StorageGuard has no account, ads, analytics, or file uploads. You can clear the local scan index and history from Settings.

Available on Android 11 and newer.
